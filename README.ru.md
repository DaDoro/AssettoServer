# AssettoServer — Living AI Traffic (fork of 0.0.54)

[English](README.md) | Русский

Форк [AssettoServer](https://github.com/compujuckel/AssettoServer) 0.0.54 с переписанным AI-трафиком. Цель — живой поток вместо «машинок на рельсах»: просветы открываются и закрываются, ряды едут с разной скоростью, машины перестраиваются и вливаются. Сделан для шашек в плотном трафике на хайвее и проверен на Shutoko Revival Project (SRP).

Всё, что не касается AI-трафика, — это AssettoServer 0.0.54: те же конфиги и тот же API плагинов, плагины для 0.0.54 работают.

## Что изменилось

- **Следование.** Вместо ванильной логики скорости — Intelligent Driver Model с эвристикой постоянного ускорения (Improved IDM). У каждой машины свой водитель: время следования 0,3–0,9 с, разгон, комфортное торможение, желаемая скорость ±5%. Машины плавно тормозят, едут колоннами и спокойно реагируют на подрезания. Ряды едут с разной скоростью, а 12% водителей медленнее своего ряда, и за ними собираются очереди.
- **Перестроения.** MOBIL поверх модели следования: машины обгоняют, держатся медленного ряда и перестраиваются только в настоящий просвет. Вежливость у водителей разная, 30% водителей агрессивные и подрезают игроков плотнее. Перестроения происходят рядом с игроками, где их видно.
- **Слияния.** На въездах, съездах и наложениях рядов машины видят соседний ряд и вливаются по очереди, «молнией»: машина со въезда выбирает просвет или ждёт, машины на главной её пропускают. Ещё машины появляются на въездах впереди игроков.
- **Спавн.** Машина не появляется там, где машине сзади пришлось бы под неё тормозить. Половина машин появляется колонной за другой машиной, остальные — в просветах.
- **Нештатные ситуации.** Реакция зависит от скорости удара: лёгкое касание — аварийка и короткое торможение, авария (от 20 км/ч) — остановка с аварийкой на 5–15 с. Стоящие препятствия (стоящий игрок, разбитая машина) машины объезжают перестроением и по очереди.
- **Визуал.** Передние колёса поворачиваются по пути, который машина реально проезжает, включая перестроения. Автомат передач, обороты и газ дают правильный звук мотора. Работает с любой моделью машины.
- **Из 0.0.55:** AI не реагирует на игроков на другом уровне (эстакады), фары по высоте солнца, сброс трафика при смене сессии.

## Установка

Скачай `assetto-server-win-x64.zip` из [Releases](../../releases) и настрой как AssettoServer 0.0.54, см. [документацию AssettoServer](https://assettoserver.org/). Чтобы перевести уже работающий сервер 0.0.54, замени его исполняемый файл на файл из релиза. Конфиги остаются те же.

## Настройка

Весь трафик форка включён по умолчанию, конфиги менять не нужно. Новые настройки — в `AiParams` файла `extra_cfg.yml`: `FollowingModel`, `Acc`, `LaneChanges`, `Merges`, `Incidents`, `Visuals`, `EnableDaytimeLights`. В свежесозданном `extra_cfg.yml` все они есть с описаниями. Чтобы выключить часть, укажи, например:

```yaml
AiParams:
  LaneChanges:
    Enabled: false
```

При старте в логе видно, что включено:

```
AI traffic: Acc following model, lane changes on, merges on, incidents on, visuals on, headlights by sun
```

Параметры командной строки:

| Параметр | Что даёт |
|---|---|
| `--ai-vanilla` | AI-трафик AssettoServer 0.0.54, для сравнения |
| `--ai-model vanilla` | ванильное следование; перестроения, слияния и нештатные ситуации выключаются, визуал остаётся |
| `--ai-model acc`, `--ai-lane-changes`, `--ai-merges`, `--ai-incidents`, `--ai-visuals` | включают часть, если она выключена в `extra_cfg.yml` |
| `--ai-trace <папка>` | запись всего AI-трафика в файл JSONL для разбора |

Админ-команды для проверки трафика: `/where` (своя позиция и ближайшая точка AI-сплайна), `/tp <x> <z> [км/ч]`, `/tppt <точка> [км/ч]`, `/tpramp [n] [км/ч]` (список въездов или телепорт перед въездом), `/tpzone <участок> [км/ч]`.

## Ограничения

Проверено только на SRP: хайвей с левосторонним движением, без перекрёстков. Городские карты и встречное движение не проверялись.

## Сборка из исходников

.NET 8 SDK или новее:

```
dotnet publish --runtime win-x64 -c Release
```

Результат — в `out-win-x64/`.
